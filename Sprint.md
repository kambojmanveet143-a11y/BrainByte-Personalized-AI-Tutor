## 🔹 Sprint 1 – Project Setup

### Objective
Set up the basic project environment and application structure.

### Tasks
- Create GitHub repository
- Set up Python environment
- Install required libraries
- Create Streamlit application
- Create basic UI
- Organize project folders
- Prepare README documentation

### Output
A basic working Streamlit project structure.

---

## 🔹 Sprint 2 – Student Profile

### Objective
Collect basic information about the student.

### Tasks
- Student name
- Class / education level
- Subject
- Topic
- Learning goal
- Preferred explanation level

### Output
A student profile that can be used by other learning modules.

---

## 🔹 Sprint 3 – Diagnostic Test

### Objective
Check the student's current knowledge level.

### Tasks
- Create topic-based diagnostic questions
- Accept student answers
- Calculate diagnostic score
- Identify strong and weak concepts
- Store performance information

### Output
A diagnostic result showing the student's current learning level.

---

## 🔹 Sprint 4 – AI Personal Tutor

### Objective
Provide personalized learning content using AI.

### Tasks
- Integrate OpenAI API
- Create personalized prompts
- Use subject, topic and learning level as context
- Use student performance and weak concepts
- Generate simple explanations
- Generate worked examples
- Display AI-generated content in Streamlit

### Output
A personalized AI Tutor that provides learning content according to the student's needs.

---

## 🔹 Sprint 5 – Adaptive Quiz System

### Objective
Provide practice questions according to the student's learning level.

### Tasks
- Generate Easy questions
- Generate Medium questions
- Generate Challenge questions
- Accept student answers
- Calculate quiz score
- Display correct/incorrect feedback

### Output
An adaptive quiz system for practice and feedback.

---

## 🔹 Sprint 6 – Mistake Analysis

### Objective
Analyze the student's mistakes after quizzes.

### Tasks
- Record incorrect answers
- Identify repeated mistakes
- Connect mistakes with concepts
- Provide feedback
- Suggest revision areas

### Output
A mistake-analysis system that identifies concepts requiring more practice.

---

## 🔹 Sprint 7 – Database & Performance Tracking

### Objective
Store student and performance information.

### Tasks
- Set up SQLite database
- Store student profile
- Store diagnostic results
- Store quiz scores
- Store performance history
- Retrieve previous results

### Output
A system for storing and tracking student performance.

---

## 🔹 Sprint 8 – Weak Topic Detection

### Objective
Identify topics where the student needs additional support.

### Tasks
- Analyze diagnostic performance
- Analyze quiz performance
- Compare scores across topics
- Identify weak concepts
- Send weak-topic information to the AI Tutor
- Recommend revision and practice

### Output
A weak-topic detection system connected with personalized learning.

---

## 🔹 Sprint 9 – Progress Dashboard & Learning Path

### Objective
Show student progress and recommend the next learning activity.

### Tasks
- Display student scores
- Show learning progress
- Show weak and improved topics
- Provide learning recommendations
- Create a personalized learning path
- Connect performance with the next activity

### Output
A progress dashboard with personalized learning recommendations.

---

## 🔹 Sprint 10 – Integration, Testing & Finalization

### Objective
Connect all modules and prepare the final project.

### Tasks
- Integrate all major modules
- Test the complete learning flow
- Fix bugs and UI issues
- Test AI responses
- Add error handling
- Check database operations
- Improve documentation
- Finalize README
- Prepare final presentation
- Prepare project demonstration

### Output
A complete and tested BrainByte prototype ready for demonstration.

The goal of BrainByte is to create a personalized learning experience where AI-generated content, quizzes and recommendations adapt according to the student's learning level and performance.
